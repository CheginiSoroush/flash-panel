# :material-cog-outline:{ .md .middle } تنظیمات مدیریت

از این بخش می‌تونید رمز پنل رو عوض کنید، پنل رو به آخرین نسخه پایدار به روز کنید یا برای همیشه از حساب خودتون حذفش کنید.

دکمه بروزرسانی به محض اینکه یه نسخه پایدار از فلش پنل منتشر بشه فعال می‌شه.

## مدیریت پنل

چهار عملیات مدیریتی، توی بخش **Settings** داشبورد پنل جمع شدن:

| عملیات | کاری که انجام می‌ده |
| --- | --- |
| **Update Panel** | آخرین نسخه‌ی پایدار از مخزن گیت‌هاب دریافت و روی همون Worker (یا پروژه Pages) دیپلوی می‌شه؛ UUID، مسیر امن و بقیه‌ی تنظیمات دست‌نخورده می‌مونن |
| **Reset Password** | رمز ورود پنل رو در KV تعیین می‌کنه؛ اگه هنوز رمزی ست نشده باشه با نام کاربری (ایمیل اکانت کلادفلر) اولین رمز ساخته می‌شه، وگرنه نیاز به نشست ورود داره؛ کوکی نشست قبلی هم پاک می‌شه |
| **Delete Panel** | اسکریپت Worker از حساب Cloudflare حذف می‌شه؛ داده‌ی KV حذف نمی‌شه و با نصب دوباره روی همون namespace برمی‌گرده |
| **Two-Factor Auth** | ورود دومرحله‌ای مبتنی بر TOTP برای پنل فعال، غیرفعال یا بازنشانی می‌شه |

!!! warning "هشدار"
    **Update Panel** و **Delete Panel** (و هر تغییری که باعث دیپلوی مجدد می‌شه) به Cloudflare API نیاز دارن. از نسخه 0.8.12 به بعد هیچ توکنی داخل سورس ورکر ذخیره نمی‌شه؛ توکن فقط توی KV (کلید `cfApiToken`) زندگی می‌کنه و باید با دستور `/cftoken` توی [بات تلگرام](telegram-bot.md) ست بشه، وگرنه این عملیات‌ها پیام صادقانه‌ی «توکن تنظیم نشده» می‌دن.

!!! note "یادداشت"
    حذف Worker باعث می‌شه Workers Route متصل به دامنه‌تون هم توسط کلادفلر حذف بشه؛ موقع نصب دوباره باید route رو برگردونید یا از ویزارد استفاده کنید.

## مرجع سریع تنظیمات ادمین

بقیه‌ی تنظیمات پنل توی فرم **Proxy Settings** هستن. جدول‌های زیر فیلدهای اصلی، نوع/مقادیر مجاز، مقدار پیش‌فرض و اثرشون رو خلاصه می‌کنن؛ توضیح کامل هر بخش توی صفحات [Common](common.md)، [VLESS و Trojan](vless-trojan.md)، [Fragment](fragment.md) و [Routing Rules](routing-rules.md) اومده.

### دسترسی و اعتبارنامه‌ها

| فیلد | نوع / مقادیر | پیش‌فرض | اثر |
| --- | --- | --- | --- |
| `VLESS UUID` | UUID معتبر | مقدار موقع دیپلوی | کلید احراز پروتکل VLESS |
| `Trojan Password` | رشته با کاراکترهای مجاز | مقدار موقع دیپلوی | رمز احراز پروتکل Trojan |
| `Panel - Subscriptions Path` (securePath) | رشته‌ی الفبایی-عددی | مقدار موقع دیپلوی | مسیر امن پنل، لینک‌های اشتراک، وب‌هوک ربات و سرور DoH |
| `Custom Domain` | دامنه | خالی | سروکردن کانفیگ‌ها با یه زیردامنه‌ی شخصی پشت کلادفلر |
| `Fallback Domain` | دامنه | خالی (پاسخ 404) | مقصد درخواست‌های نامعتبر به‌جای 404 |
| `Underlying DoH` | آدرس `https://…/dns-query` | خالی → `cloudflare-dns.com/dns-query` | سرور بالادستیِ سرور DoH شخصی پنل |

!!! info "راهنمایی"
    فیلدهای بخش «دسترسی و اعتبارنامه‌ها» (و همچنین Proxy IP و NAT64 Prefix) وابسته به دیپلوین؛ با تغییرشون ورکر خودکار با تنظیمات جدید دوباره دیپلوی می‌شه و چند ثانیه طول می‌کشه.

!!! warning "هشدار"
    تغییر UUID یا securePath همه‌ی لینک‌های اشتراک رو نامعتبر می‌کنه؛ بعد از اعمال، کلاینت‌ها باید اشتراک رو دوباره وارد یا آپدیت کنن وگرنه قطع می‌شن. تغییر securePath خودش وب‌هوک ربات تلگرام رو با مسیر جدید دوباره ثبت می‌کنه، ولی لینک‌های قدیمی که توی دست کاربرهاست دیگه کار نمی‌کنه.

### پروتکل‌ها، پورت‌ها و Fragment

| فیلد | نوع / مقادیر | پیش‌فرض | اثر |
| --- | --- | --- | --- |
| `Protocols` | `vless,trojan` / `vless` / `trojan` | `vless,trojan` | پروتکل‌های فعال در کانفیگ‌ها |
| `Ports` | چند انتخابی | فقط 443 | پورت‌های کانفیگ‌ها؛ حداقل یک پورت TLS الزامیه |
| `Fragment Mode` | `custom` / `low` / `medium` / `high` | `custom` | شدت تکه‌تکه‌کردن TLS برای دور زدن فایروال |
| `Fragment Packets` | `tlshello` / `1-1` / `1-2` / `1-3` / `1-5` | `tlshello` | کدوم پکت‌ها fragment بشن |
| `Fragment Length` | بازه‌ی عددی | 100 تا 200 | طول هر تکه |
| `Fragment Delay` | بازه‌ی عددی | 1 تا 1 | تأخیر بین تکه‌ها (میلی‌ثانیه) |
| `Fragment Max Split` | بازه‌ی عددی | 0 تا 0 | سقف تعداد تکه‌ها در هسته‌ی Xray |

### Clean IP و DNS

| فیلد | نوع / مقادیر | پیش‌فرض | اثر |
| --- | --- | --- | --- |
| `Clean IPs - Domains` | لیست IP/دامنه، هر خط یک مورد | `www.speedtest.net` | آدرس‌های تمیز پشت کلادفلر در کانفیگ‌ها |
| `Clean IPs First` | بولی | خاموش | اولویت‌دادن به Clean IPها — ضد خطای 403 |
| `Best Interval` | ثانیه | 30 | فاصله‌ی تست مجدد کانفیگ‌های **Best Ping** |
| `Local DNS` | IPv4 یا `localhost` | `8.8.8.8` | DNS داخل کانفیگ‌ها برای مسیریابی |
| `Remote DNS` | DoH / DoT / TCP | `https://8.8.8.8/dns-query` | DNS رمزشده‌ی خروجی — سرورهای Cloudflare مجاز نیستن |
| `Anti Sanction DNS` | IP یا دامنه | `178.22.122.100` (Shecan) | رفع تحریم دامنه‌های مسیریابی‌شده |
| `Warp Remote DNS` | فقط IPv4 | `1.1.1.1` | DNS اشتراک‌های Warp |

### متفرقه

| فیلد | نوع / مقادیر | پیش‌فرض | اثر |
| --- | --- | --- | --- |
| `Log Level` | none / warning / error / info / debug | `warning` | سطح گزارش‌های هسته‌ی کلاینت |
| `IPv6` | بولی | خاموش | اضافه‌شدن کانفیگ‌های IPv6 |
| `Fake DNS` | بولی | خاموش | کم‌کردن تأخیر DNS (با احتیاط) |
| `Allow connections from LAN` | بولی | خاموش | اجازه‌ی استفاده‌ی دستگاه‌های شبکه‌ی محلی |
| `TCP Fast Open` | بولی | خاموش | کاهش تأخیر برقراری اتصال |
| `Fingerprint` | chrome / firefox / safari / ios / android / edge / randomized و… | `chrome` | اثر انگشت TLS کانفیگ‌ها |
| `ECH` | بولی | خاموش | رمزگذاری SNI با ECH کلادفلر |
| `WS Guardian` | بولی | خاموش | بستن اتصال‌های زامبی شبکه‌ی موبایل |
| `WS Guardian Timeout` | 30 تا 3600 ثانیه | 300 | آستانه‌ی بی‌تفاوتی دوطرفه برای نگهبان |

!!! tip "نکته"
    کنار دکمه‌ی `Apply Settings` یه دکمه‌ی `Reset Settings` هست که همه‌ی این فیلدها رو به پیش‌فرض برمی‌گردونه، پس نگران خراب‌کردن تنظیمات نباشید. بعد از هر تغییر هم باید اشتراک‌ها رو توی کلاینت‌ها آپدیت کنید.
