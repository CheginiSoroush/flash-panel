# :material-cog-outline:{ .md .middle } بات تلگرام

ربات تلگرام شما از اینجا قابل راه‌اندازی هست. اول باید یه Token API از `@BotFather` بگیرید و بعد شناسه کاربری یا user ID رو از `@userinfobot` دریافت کنید و اینجا وارد کنید. BotFather لینک ربات رو به شما می‌ده.

ربات تلگرام فلش پنل می‌تونه برای دریافت لینکای اشتراک، کدهای qr، فایل های کانفیگ، نظارت بر استفاده و دانلود آخرین نسخه کلاینت‌های پشتیبانی شده برای راحتی شما استفاده بشه.

## راه‌اندازی

1. توی تلگرام به `@BotFather` پیام بدید، با دستور `/newbot` یه ربات بسازید و توکنش (به شکل `123456:ABC-DEF…`) رو کپی کنید.
2. به `@userinfobot` پیام بدید و شناسه‌ی عددی خودتون (مثل `123456789`) رو بردارید.
3. توی پنل، بخش **Telegram Bot** رو باز کنید، توکن و User ID رو وارد کنید و روی **Setup** بزنید.

پنل به‌صورت خودکار دو کار انجام می‌ده: ثبت وب‌هوک روی آدرس `https://<دامنه‌ی پنل>/<securePath>/telegram/webhook` (با یه توکن مخفی مشتق‌شده از توکن ربات) و ثبت فهرست دستورهای ربات. دکمه‌ی **Remove** وب‌هوک رو حذف می‌کنه، آپدیت‌های در صف رو دور می‌ریزه و تنظیمات ربات رو از KV پاک می‌کنه.

!!! warning "هشدار"
    وب‌هوک روی دامنه‌ی شخصیِ ورکر ثبت می‌شه؛ روی `workers.dev` (که طبق سیاست امنیتی پنل غیرفعاله) کار نمی‌کنه. اگه دامنه یا securePath رو عوض کردید، یک بار دوباره **Setup** رو بزنید — البته تغییر securePath از خود پنل، وب‌هوک رو خودکار با مسیر جدید ثبت می‌کنه.

!!! info "امنیت"
    - فقط پیام‌های ادمین (همون User ID ثبت‌شده) پردازش می‌شن؛ هر کاربر دیگه‌ای بی‌پاسخ رد می‌شه.
    - هر آپدیت وب‌هوک با هدر `X-Telegram-Bot-Api-Secret-Token` اعتبارسنجی می‌شه، پس کسی که آدرس وب‌هوک رو حدس بزنه هم نمی‌تونه آپدیت جعلی بفرسته.
    - توکن ربات فقط توی KV ذخیره می‌شه و هیچ‌جا بازتاب داده نمی‌شه.

## دستورهای ربات

| دستور | توضیح |
| --- | --- |
| `/start` | نمایش منوی اصلی با دکمه‌های شیشه‌ای |
| `/config` | دریافت کانفیگ‌ها: انتخاب نوع اشتراک Normal / Fragment / Raw / Warp / Warp Pro |
| `/clients` | فهرست برنامه‌های پشتیبانی‌شده با حداقل نسخه و لینک دانلود آخرین نسخه |
| `/tg` | راهنمای عبور تلگرام از تونل خود کانفیگ‌ها (بدون نیاز به پروکسی MTProto جدا) |
| `/usage` | مصرف امروز درخواست‌های Cloudflare Workers (پنل و کل اکانت) |
| `/users` | فهرست کاربران اشتراک چندکاربره با آمار واکشی و صفحه‌بندی |
| `/digest` | خلاصه‌ی روزانه: مصرف + وضعیت کاربران |
| `/edge` | تله‌متری لبه‌ی کلادفلر: دیتاسنتر، ISP و تأخیر کاربران |
| `/broadcast` | ارسال پیام به همه‌ی کاربران متصل به ربات |
| `/settings` | تغییر تنظیمات پنل از داخل چت |
| `/cftoken` | ست‌کردن یا مشاهده‌ی وضعیت توکن Cloudflare API (ادمین) |

دکمه‌های **Status** (وضعیت پنل، نسخه، مصرف و چند toggle مسیریابی) و **Restart** (باطل‌کردن کش تنظیمات) هم توی منوی اصلی هستن و همون‌کار دستورهای `/status` و `/restart` رو می‌کنن.

## دریافت لینک اشتراک از ربات

با `/config` یا دکمه‌ی **Get Config**، اول نوع اشتراک رو انتخاب می‌کنید. برای هر هسته، ربات یه QR code، لینک اشتراک و فایل کانفیگ JSON می‌فرسته:

- برای **sing-box** لینک به‌صورت deep link `sing-box://import-remote-profile` میاد که با یک لمس ایمپورت می‌شه.
- برای دسته‌ی **WireGuard / Amnezia** (توی اشتراک Warp و Warp Pro) به‌جای QR و JSON، فایل زیپ کانفیگ ارسال می‌شه.
- اگه ارسال QR به هر دلیلی شکست بخوره، لینک متنی جایگزین می‌شه تا دکمه بی‌جواب نمونه.

## مدیریت کاربران و Broadcast

دستور `/users` کاربران اشتراک چندکاربره رو نشون می‌ده: فعال یا ابطال‌شده، تعداد واکشی هر کدوم و جزئیات تک‌تک‌شون. از صفحه‌ی هر کاربر می‌تونید لینک‌های شخصی‌ش (Normal و Raw) رو دوباره بفرستید؛ اگه کاربر به ربات وصل شده باشه، لینک مستقیم به چت خودش می‌ره.

با `/broadcast` یه پیام برای همه‌ی گیرنده‌ها (ادمین + کاربران متصل به ربات) می‌فرستید. متن می‌تونه از جای‌نگهدارهای `<code>{name}</code>` (نام کاربر)، `<code>{link}</code>` (لینک اشتراک شخصی‌ش) و `<code>{uuid}</code>` استفاده کنه. ربات اول پیش‌نمایش نشون می‌ده و بعد از تأیید، گزارش «ارسال‌شده / ناموفق» می‌ده.

## تغییر تنظیمات از ربات

با `/settings` می‌تونید بدون باز کردن پنل این فیلدها رو عوض کنید: Local DNS، Remote DNS، Protocols، Clean IPs (حداکثر ۵۰ مورد)، Fingerprint، نگهبان WS و Timeout اون، و toggleهای مسیریابی (Bypass ایران/چین/روسیه/OpenAI/Google AI/Microsoft/Oracle/Docker و Block تبلیغات/پورن/بدافزار/فیشینگ/ماینر). ربات مقدار فعلی رو نشون می‌ده، اعتبارسنجی می‌کنه و بعد از ذخیره‌ی موفق تأیید می‌ده.

!!! note "یادداشت"
    فیلدهای حساس مثل UUID، رمز Trojan، securePath و دامنه‌ی شخصی از ربات قابل تغییر نیستن و باید از پنل انجام بشن.

## مصرف Cloudflare

دستور `/usage` و دکمه‌ی **Usage** تعداد درخواست‌های امروز رو در برابر سقف ۱۰۰,۰۰۰ درخواست رایگان نشون می‌دن (جدا برای پنل و کل اکانت). دیتا کش ۶۰ ثانیه‌ای داره و اگه مصرف از ۸۰٪ بگذره، ربات حداکثر ساعتی یک‌بار هشدار می‌ده.

## توکن Cloudflare API با `/cftoken`

از نسخه 0.8.12 به بعد، توکن Cloudflare API (که فیچرهایی مثل **Update Panel**، نمودار مصرف، مدیریت دامنه‌ها و Pages رو تغذیه می‌کنه) هرگز داخل سورس ورکر ذخیره نمی‌شه — همین الگوی «اعتبارنامه در سورس» قبلاً باعث بلاک‌شدن ورکر توسط اسکنر کلادفلر شده بود. توکن فقط توی KV با کلید `cfApiToken` زندگی می‌کنه:

- `/cftoken` بدون آرگومان → وضعیت فعلی؛ توکن به‌صورت ماسک‌شده (فقط ۴ کاراکتر آخر) یا «not configured» نمایش داده می‌شه.
- `/cftoken <token>` → ذخیره در KV + تأیید زنده نزد کلادفلر؛ پاسخ «CF says: active» یا متن خطای واقعی کلادفلر برمی‌گرده.

!!! warning "هشدار امنیتی"
    توکن رو فقط از کانال مطمئن بفرستید، برای کارهای روزمره از توکن Custom اسکوپ‌دار (نه Global API Key) استفاده کنید و بعد از هر گمانه‌زنی به نشتی، همون دستور `/cftoken` با توکن جدید عملاً توکن قبلی رو عوض می‌کنه. توکن کامل در هیچ پیام یا لاگی بازتاب داده نمی‌شه.

## عیب‌یابی

- **ربات هیچ جوابی نمی‌ده:** مطمئن شوید پیام از همان User ID ثبت‌شده است. بعد یک بار **Remove** و دوباره **Setup** کنید تا وب‌هوک با secret درست ثبت بشه؛ `last_error` وب‌هوک معمولاً علت را لو می‌دهد (دامنه‌ی مرده، TLS ناقص و…).
- **پیام «Save failed» هنگام تغییر تنظیمات:** یعنی نوشتن KV موقتاً زیر سقف روزانه‌ی کلادفلر گیر کرده. چند لحظه بعد دوباره امتحان کنید؛ به پرامپت ربات هم می‌تونید **reply** کنید تا بدون ذخیره‌ی حالت انتظار کار کنه.
- **دکمه‌های منو بی‌عمل:** پیام قدیمی کش‌شده است؛ `/start` بزنید تا منوی تازه بیاد.
- **بعد از تغییر دامنه/securePath ربات ساکت شد:** Setup را تکرار کنید تا وب‌هوک روی آدرس جدید ثبت بشه.
