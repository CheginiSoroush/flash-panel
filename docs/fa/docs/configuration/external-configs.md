# :material-cog-outline:{ .md .middle } اضافه کردن کانفیگ‌های شخصی

به راحتی میتونید چند لینک اشتراک شخصی و حتی کانفیگ شخصی رو به این قسمت اضافه کنید. فلش پنل تمام کانفیگای این دو بخش رو میخونه و در لینک اشتراک Raw با کانفیگای فلش پنل تجمیع می‌کنه.

لطفا دقت کنید یه مشکل عدم سازگاری در هسته‌ها وجود داره، مثلا هسته sing-box از XHTTP پشتیبانی نمیکنه، بنابراین اگر کانفیگای شخصیتون شامل این پروتکل‌ها باشه روی v2rayNG کار میکنه و روی Nekobox یا husi کار نمی‌کنه برای مثال.

## دو فیلد و کار هر کدام

| فیلد | قالب پذیرفته‌شده | رفتار |
| --- | --- | --- |
| `Custom Configs` | هر خط یک لینک کانفیگ آماده: `vless://`، `vmess://`، `trojan://`، `ss://`، `socks://`، `http://` | متن همان خط‌ها بدون تغییر، بعد از کانفیگ‌های پنل به اشتراک اضافه می‌شه |
| `Custom Subscriptions` | هر خط یک URL معتبر (لینک اشتراک بیرونی) | در هر درخواست اشتراک Raw، لینک‌ها fetch می‌شن و محتواشون الحاق می‌شه |

اعتبارسنجی موقع **Apply** انجام می‌شه: آدرس‌های بیرونی باید URL معتبر باشن وگرنه خطای `External Raw subscriptions - Invalid URLs` می‌گیرید. برای فیلدهای لیستی، هر مورد رو در یک خط جدید وارد کنید.

## کجا ظاهر می‌شن؟

فقط توی اشتراک **Raw** (`/{securePath}/sub/raw`) که لینکش رو از ربات یا پنل می‌گیرید. ترتیب نهایی خروجی این‌طوریه:

1. کانفیگ‌های VLESS و Trojan خود پنل (بر اساس پورت‌ها، Clean IPها و دامنه‌ی شخصی)
2. کانفیگ **Chain Proxy** (اگر ست شده باشه)
3. کانفیگ‌های شخصی شما از `Custom Configs`
4. کانفیگ‌های واکشی‌شده از `Custom Subscriptions`

خروجی اشتراک Raw به‌صورت Base64 ارائه می‌شه، پس هر دوتا هسته‌ی `app=xray` و `app=sing-box` همین محتوا رو می‌گیرن؛ برنامه‌های مبتنی بر Clash این اشتراک رو پشتیبانی نمی‌کنن.

## رفتار واکشی لینک‌های اشتراک

- لینک‌ها هنگام تولید هر نسخه‌ی تازه‌ی اشتراک Raw از سمت ورکر fetch می‌شن؛ چون خروجی اشتراک حدود ۵ دقیقه توی سطح isolate کش می‌شه، چند درخواست پشت‌سرهم معمولاً فقط یک‌بار واکشی ایجاد می‌کنه.
- پاسخ غیر 200 یا بدنه‌ی خالی → اون لینک بی‌صدا از خروجی حذف می‌شه (بقیه‌ی کانفیگ‌ها سالم می‌مونن).
- اگه محتوای لینک Base64 باشه خودکار decode می‌شه؛ متن خام (لینک‌های `vless://…` زیر هم) همون‌طور که هست الحاق می‌شه.

## نکات و ریسک‌ها

!!! warning "هشدار"
    هر لینک بیرونی یه درخواست اضافه‌ی ورکر به ازای هر آپدیت اشتراک داره. لینک‌های کند یا جواب‌دهِ ناپایدار هم سرعت آپدیت ساب رو کم می‌کنن و هم گاهی «چرا کانفیگ‌هام کم شدن؟» می‌سازن، چون لینک مُرده بی‌صدا حذف می‌شه.

- **حریم خصوصی:** لینکی که خودتون از جایی گرفته‌اید و توکن داره رو عمومی منتشر نکنید؛ واکشی از سمت ورکر شما انجام می‌شه و لاگ سمت لینک‌دهنده ثبت می‌شه.
- **سازگاری هسته‌ها:** کانفیگ‌های شخصی توسط پنل باز و بازنویسی نمی‌شن؛ پروتکل/ترنسپورت‌هایی که هسته‌ی مقصد نداره (مثل XHTTP روی هسته‌های قدیمی sing-box) فقط روی برنامه‌های مبتنی بر Xray جواب می‌دن.
- **کانفیگ تکراری:** کانفیگی که هم خود پنل می‌سازه هم توی لینک بیرونی هست، دوبار توی برنامه ظاهر می‌شه — نگران نباشید ولی برای تمیز ماندن لیست از اضافه‌کردن تکراری خودداری کنید.
- **اشتراک Raw نیازمند تنظیم دستیه:** Remote DNS باید توی برنامه روی DoH/DoT/TCP ست بشه و Mux خاموش باشه؛ جزئیات توی صفحه‌ی [اشتراک Raw](../usage/raw.md) اومده.

!!! tip "نکته"
    تغییر این دو فیلد تغییری توی کانفیگ‌های سروری پنل نمی‌ده؛ فقط بعد از Apply و آپدیت اشتراک توی برنامه، کانفیگ‌های جدید رو می‌بینید.
