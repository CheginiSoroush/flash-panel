## معرفی

فلش پنل به شما اجازه می‌ده روی اکانت Cloudflare خودتون یه سرور پروکسی شخصی با **VLESS** و **Trojan** راه بندازید — بدون نیاز به سرور، IP یا دامنه‌ی پولی (در صورت استفاده از ویزارد).

**مخاطب:** کاربرانی که می‌خوان یه پروکسی شخصی امن داشته باشن.

**نیازمندی‌ها:**
- یه اکانت Cloudflare (رایگان)
- [Node.js](https://nodejs.org) نسخه ۲۲+ (برای نصب دستی)
- (توصیه‌شده) یه دامنه شخصی — [چرا؟](#دامنه-اختصاصی)

## امکانات

| قابلیت | توضیح |
|---------|--------|
| ⚡ **پروتکل‌های VLESS + Trojan** | با WebSocket + TLS |
| 🌐 **Warp + Warp Pro** | پشتیبانی کامل |
| 📱 **سابسکریپشن خودکار** | برای همه کلاینت‌ها (v2rayNG, sing-box, Clash...) |
| 🔗 **DoH اختصاصی** | سرور DNS over HTTPS |
| 📡 **ربات تلگرام** | مدیریت از تلگرام |
| 🧩 **Fragment** | دور زدن فیلترینگ TLS |
| 🔄 **آپدیت خودکار** | از GitHub خودت |
| 🧪 **۲۲ تست خودکار** + CI | روی هر تغییر |

## نصب سریع

### 🪄 با فلش ویزارد (پیشنهادی)

۱. برید به [فلش ویزارد](https://flash-wizard.imsoroush.workers.dev/)
۲. توکن API از [اینجا](https://dash.cloudflare.com/profile/api-tokens) بسازید (قالب **Edit Cloudflare Workers**)
۳. دامنه‌تون رو وارد کنید
۴. دکمه «نصب کن» 🚀
